# Deep Research 技能

## 工作流程

1. **理解问题** — 分析用户的问题，拆解为可搜索的子问题
2. **逐步搜索** — 使用 bash 工具执行搜索命令:
   - 用 curl 调用搜索引擎 API
   - 或用 bash 执行命令行搜索工具
3. **整合信息** — 将搜索结果整理为结构化的回答
4. **交叉验证** — 如果有矛盾的信息，标注来源并说明
5. **输出报告** — 格式化为清晰的 Markdown，包含:
   - 概述（2-3 句话）
   - 详细分析（分章节）
   - 来源引用

## 注意事项
- 不要编造信息，只报告搜索到的内容
- 如果搜索结果不够，明确告知用户并建议换关键词
- 保持客观中立
