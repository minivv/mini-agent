# Code Review 技能

## 工作流程

1. **理解代码** — 读取用户提供的代码文件，理解其目的和结构
2. **多维度审查** — 从以下角度检查:
   - 正确性: 逻辑是否正确？有没有 bug？
   - 可读性: 命名是否清晰？结构是否合理？
   - 安全性: 有没有注入、XSS、越权等安全问题？
   - 性能: 有没有明显的性能问题？
   - 最佳实践: 是否遵循了语言/框架的最佳实践？
3. **分级报告** — 按严重程度分类:
   - 🔴 必须修复: 会导致 bug 或安全漏洞
   - 🟡 建议修复: 影响可维护性或性能
   - 🟢 可选优化: 纯粹的改进建议
4. **给出具体修改建议** — 不要只说"有问题"，要给出具体的修改方案和代码示例
